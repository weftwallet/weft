A small dApp for trying Weft. It works with any network that publishes an [org invite](/operators/invites/).

- **On your machine:** run `pnpm playground:up` in the Weft repository. It starts Fabric's test network with the `basic` asset contract and a relay, and this page finds it automatically. See [Local test network](/dapps/test-network/).
- **Your own network:** paste your organisation's invite URL below, or open this page with `?invite=<url>`.
